# HTML → PDF Studio

A professional-grade, browser-based utility for generating high-quality PDFs from HTML content[cite: 1]. Built with privacy and performance in mind, this tool runs entirely on the client side[cite: 1].

## 🚀 Features

* **Dual-Input Mode**: Upload existing .html files or paste code directly into the built-in editor[cite: 1].
* **Smart Formatting**: Automatically applies print-optimized styles to ensure clean margins, typography, and page breaks[cite: 1].
* **Document Analysis**: Get instant statistics on your document, including estimated page count, word count, and potential layout warnings[cite: 1].
* **Advanced PDF Control**: Customize paper size, orientation, margins, and image quality[cite: 1].
* **Privacy-Focused**: All processing happens locally in your browser—your data is never uploaded to a server[cite: 1].
* **Dark Mode Support**: Seamless toggle between light and dark themes for comfortable editing[cite: 1].

## 🛠 Tech Stack

* **Core Logic**: Vanilla JavaScript[cite: 1].
* **PDF Generation**: [jsPDF](https://github.com/parallax/jsPDF)[cite: 1].
* **Rendering**: [html2canvas](https://github.com/niklasvh/html2canvas)[cite: 1].
* **Editor**: [CodeMirror](https://codemirror.net/)[cite: 1].

## 📦 Getting Started

1. Clone this repository or download.
2. Open the file in any modern web browser.
3. Load your content via the "Upload" or "Paste" tab.
4. Configure your desired PDF settings in the sidebar.
5. Click **Generate Professional PDF** to create and download your document.
